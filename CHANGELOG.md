# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-01-04

### Added
- Initial release
- FormManager for centralized form handling
- FormTextInput with regex validation
- FormToggleInput for checkboxes
- FormDropdown for TMP_Dropdown
- FormSliderInput with value display
- DoubleSlider for range selection
- RadioboxFormInput for radio groups
- PhoneNumberInput with country codes
- DateTimeInput with dropdown pickers
- ColorPicker (color wheel)
- ColorPickerInput (hex + RGB sliders)
- CountryCodeHandler utility
